# Business Design 상세 가이드

> PPT 템플릿 제작을 위한 와이 커뮤니케이션 Business 디자인 시스템

---

## 1. 컬러 시스템 (Color System)

| 역할 | 색상 코드 | 설명 |
|------|----------|------|
| **Primary (Deep Black)** | `#1a1a1a` | 메인 배경색, 고급스러운 느낌 |
| **Secondary (Champagne Gold)** | `#c9a962` | 강조 포인트, 타이틀 하이라이트 |
| **Secondary Dark** | `#b39550` | 호버/다크 버전 골드 |
| **Accent (Charcoal)** | `#2d3436` | 카드/보조 배경색 |
| **Background (Warm Off-White)** | `#faf9f7` | 밝은 배경 (거의 사용 안 함) |
| **텍스트 (White)** | `#ffffff` | 주요 텍스트 |
| **보조 텍스트** | `rgba(255,255,255,0.6~0.7)` | 설명 텍스트 |

### 컬러 조합 가이드

```
배경: #1a1a1a (Deep Black)
├── 강조 텍스트: #c9a962 (Champagne Gold)
├── 주요 텍스트: #ffffff (White)
├── 보조 텍스트: rgba(255,255,255,0.6)
└── 카드 배경: #2d3436 (Charcoal) 또는 #222
```

## 2. 타이포그래피 (Typography)

### 폰트 패밀리

| 용도 | 폰트 | 스타일 |
|------|------|--------|
| **헤드라인 (한글)** | `'Noto Serif KR', serif` | `font-weight: 700~900`, `letter-spacing: -0.03em` |
| **영문 레이블** | 기본 sans-serif (Pretendard) | `uppercase`, `tracking-widest (0.1em+)` |
| **본문** | Pretendard | 일반 weight |

### 크기 가이드 (PPT 환경 권장)

| 용도 | 크기 |
|------|------|
| 메인 타이틀 | 48~60pt |
| 서브 타이틀 | 32~40pt |
| 섹션 헤더 | 24~32pt |
| 본문 | 14~18pt |
| 영문 레이블 | 10~12pt (대문자) |

## 3. 레이아웃 패턴

### Hero 섹션 패턴

- **배경**: 어두운 이미지 + 그라데이션 오버레이
  ```css
  linear-gradient(rgba(26, 26, 26, 0.85), rgba(45, 52, 54, 0.9))
  ```
- **골드 디바이더 라인**: 3px 높이, 60~80px 너비
- **타이틀 구조**: 줄바꿈으로 강조
  - 조직의 DNA를 분석하고,
  - **비즈니스의 격을** (골드 색상)
  - 설계합니다.
- **메인 카피**: "차가운 마이크에 진심의 온기를, 브랜드의 언어에 전략적 가치를 더합니다."
- **CTA 버튼**: 골드 배경 + 블랙 텍스트, 또는 골드 테두리 + 투명 배경

### Intro/About 섹션 패턴

- **2컬럼 레이아웃**: 좌측 1/3 (타이틀 영역) + 우측 2/3 (카드 영역)
- **카드 디자인**:
  - 상단에 골드 보더 (2px)
  - 배경: `#2d3436` 또는 `#222`
  - 아이콘 컬러: 골드

### Portfolio/Announcer CTA 섹션 패턴

- **전체 화면 배경 이미지** + 다크 그라데이션 오버레이
  ```css
  linear-gradient(to right, rgba(0,0,0,0.95), rgba(26,26,26,0.8))
  ```
- 큰 타이틀 + 간결한 설명 + 버튼
- **버튼**: 화이트 테두리 + 투명 배경, 호버 시 반전

### Curriculum 2x2 그리드 패턴

- 4개 카드를 2x2 배열
- 각 카드: 이미지 + 오버레이 + 뱃지 + 타이틀 + 설명
- **뱃지**: 골드 텍스트, 블랙 반투명 배경, 골드 보더

## 4. 주요 UI 요소

### 골드 디바이더 (Gold Divider)

```
너비: 48~80px
높이: 2~3px
컬러: #c9a962
위치: 섹션 타이틀 위 또는 콘텐츠 시작 전
```

### 영문 레이블 (Section Label)

```
폰트 크기: 10~12px
색상: #c9a962
스타일: uppercase, tracking-widest
예시: "ABOUT US", "EDUCATION CURRICULUM", "CLIENT LIST"
```

### 카드 스타일

```
배경: #2d3436 또는 rgba(255,255,255,0.03)
테두리: 상단 2px solid #c9a962
모서리: 0 (사각형) 또는 약간의 radius
```

### 버튼 스타일

| 타입 | 배경 | 글자색 | 테두리 |
|------|------|--------|--------|
| **Primary** | `#c9a962` | `#1a1a1a` | 없음 |
| **Secondary** | 투명 | `#c9a962` | `2px solid #c9a962` |
| **Ghost (White)** | 투명 | 흰색 | `2px solid white` |

## 6. 이미지 처리

### CEO 사진
- **골드 프레임 장식**: 좌상단/우상단 코너 라인
- 그레이스케일 처리 (호버 시 컬러 복원 가능)

### 배경 이미지
- **패럴럭스 효과**: `background-attachment: fixed`
- 다크 오버레이 필수 적용

### 파트너 로고
- **grayscale + invert** 처리로 화이트 톤 유지
- 호버 시 컬러 복원

### 교육 이미지
- 약간의 오버레이 + 그라데이션
- 하단에서 상단으로 그라데이션

## 7. 핵심 디자인 원칙

### 프리미엄 & 절제미
과도한 장식 대신 여백과 골드 포인트로 고급스러움 표현

### 다크 모드 기반
어두운 배경으로 집중도와 세련미 향상

### 골드 = 강조
핵심 키워드, 버튼, 아이콘, 디바이더에만 골드 사용

### 명확한 위계
영문 레이블 → 한글 타이틀 → 본문 순서로 시각적 흐름 유도

### 여백 활용
충분한 패딩/마진으로 고급스러운 느낌 연출
